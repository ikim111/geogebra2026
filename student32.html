어떤 조건만 있으면 △ABC ∽ △DEF 일까?

닮은 두 삼각형은 대응변의 길이의 비가 같고(1 : 2), 대응각의 크기가 같아요. 모두 6가지예요.
아래에서 조건을 골라 「그려 보기」를 누르면, 그 조건만 지키는 △DEF를 그려 줘요. 여러 번 그려도 항상 △ABC와 닮은 삼각형이 나오는 가장 적은 조건을 모두 찾아보세요.

⭐ 찾은 최소 조건 0 / 7

📦 정리: 삼각형의 닮음 조건

두 삼각형은 다음 중 하나만 맞으면 닮은 도형이에요. 6가지를 다 확인하지 않아도 돼요!

① SSS 닮음세 쌍의 대응변의 길이의 비가 같다a : a′ = b : b′ = c : c′
② SAS 닮음두 쌍의 대응변의 길이의 비가 같고, 그 끼인각의 크기가 같다a : a′ = c : c′, ∠B = ∠B′
③ AA 닮음두 쌍의 대응각의 크기가 각각 같다∠B = ∠B′, ∠C = ∠C′

S는 Side(변), A는 Angle(각)의 첫 글자예요. 다음 화면부터 이 조건으로 2배 닮은 삼각형을 직접 작도해 봐요.

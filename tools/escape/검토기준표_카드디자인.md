# 방탈출 카드 디자인 검토 기준표

카드의 생김새(정보 위계·글·글씨체·아이콘·그림·틀·규칙·인쇄)를 본다. 게임 내용은 `검토기준표_플레이.md`로 본다.
**진행 순서**: 자동 검사 → 카드 한 장씩 검토 → 문제 목록 표 → 글씨체·뒷면 등 디자인은 시안 승인 → 한꺼번에 수정

## 근거
- 카드 그래픽 디자인 6원칙 (Shufflekit): 정보 위계, 글 길이, 아이콘, 60cm 거리에서 읽기, 같은 틀 — https://shufflekit.com/blog/game-card-graphic-design-rules
- 카드 글씨체 팁 (Daniel Solis, 게임 디자이너): 글 2~3줄, 크기, 줄 간격 1.5배, 그림이 글을 보여 주기 — https://danielsolisblog.blogspot.com/2011/11/5-graphic-design-and-typography-tips.html
- 보드게임 접근성 평가 도구 (Heron 외, 2018, *Computer Games Journal*, Meeple Centred Design): 색맹, 시각·인지 부담 — https://rgu-repository.worktribe.com/output/247174/meeple-centred-design-a-heuristic-toolkit-for-evaluating-the-accessibility-of-tabletop-games
- 인쇄 기준 (PandaGM 인쇄소 가이드): 여백 3mm, 300ppi, 글자는 순수 검정 — https://pandagm.com/wp-content/uploads/2022/10/PandaGM-GraphicDesignGuidebook-V4-0922.pdf
- 실제 언락 카드: 뒷면은 테마 그림 + 가운데 번호, 벌점 카드만 버리기 — https://stopnow.tistory.com/45
- 방탈출 설계 기준 (Nicholson)

## 기준표
| 영역 | 기준 | 근거 | 검사 |
|---|---|---|---|
| **1. 정보 위계** | 번호와 종류(색 띠)가 가장 크고 먼저 보임, 제목 다음, 설명은 그다음 | Shufflekit ① | 눈으로 |
| | 카드끼리 겹쳐 놓아도 번호·색이 보임(왼쪽 위) | Shufflekit ② | 겹쳐 놓고 확인 |
| **2. 글** | 설명 **2~3줄 이내** | Solis ①, Shufflekit ③ | 자동 |
| | 잘림·넘침 없음 | — | 자동 |
| | 정답 유도 문구 없음("무엇과 합쳐 볼까", "(10+11)", "(연습)") | 언락 방식 | 자동 |
| | 디벗 사용법은 연습·규칙 카드에만 | 언락 방식 | 자동 |
| | 비문 없음, 수학 조건이 정확하고 굵게 | 수업 자료 기준 | 한 장씩 |
| **3. 글씨체** | 장식 없이 읽기 쉬운 글꼴, **두 가지 이내**(제목용 1 + 본문용 1) | Solis ③ | 시안 비교 |
| | 본문 크기: 팔 길이에서 읽힘(이 카드 크기로는 **8pt 이상**), 줄 간격 1.5배 | Solis ③ | 자동 + 인쇄 |
| | 글 뒤 배경은 무늬 없고 대비가 큼 | Solis ④ | 눈으로 |
| **4. 아이콘·색** | 세 장 넘게 나오는 표현은 기호로 바꾸고 규칙 카드에 설명 | Shufflekit ④ | 눈으로 |
| | 색만으로 구별하지 않음(모양도 같이) | Heron 2018 | 눈으로 |
| **5. 그림** | 그림이 글 내용을 보여 줌(글을 가려도 뜻이 통함) | Solis ⑤ | 한 장씩 |
| | 번호는 실제 물건 위, 중요한 곳을 가리지 않음 | 언락 방식 | 한 장씩 |
| | 숨은 번호는 또렷하지만 눈에 안 띔 | 언락 방식 | 인쇄 크기로 |
| | 그림체 통일 | Shufflekit ⑥ | 모아 보기 |
| **6. 틀** | 모든 카드가 같은 틀(번호·띠·그림·글 자리 고정) | Shufflekit ⑥ | 눈으로 |
| | 뒷면은 테마 그림 + 가운데 번호만 | 언락 사진 | 시안 승인 |
| **7. 게임 규칙** | 벌점 카드는 **자기만** 버림, 원래 카드는 남김 | 언락 규칙 | 자동 |
| | 버리기 표시와 번호 겹침, 끝까지 갈 수 있는지 | Nicholson | 시뮬레이션 |
| | 카드 문장과 디벗 안내가 서로 맞음 | — | 대조 |
| **8. 인쇄** | 자르는 선 안쪽 3mm에는 글자 없음, 그림 300ppi 이상 | PandaGM | 자동 |
| | 앞뒤 맞춤, 3장 시험 인쇄 후 60cm 거리에서 읽기 | Shufflekit ⑤ | 선생님 인쇄 |
